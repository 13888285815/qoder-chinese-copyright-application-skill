📄 中国软件著作权申请材料生成器

自动生成符合中国版权保护中心要求的软件著作权申请材料

主要功能

  • 自动生成软件著作权登记申请表
  • 自动生成源代码文档（前后各30页）
  • 自动生成用户手册
  • 自动生成设计说明书
  • 支持导出 Word、PDF、 Markdown 格式
  • 支持在线编辑和实时预览
  • 符合2026年最新政策要求

💡 如何使用

1. 克隆项目到本地
git clone https://github.com/13888285815/qoder-chinese-copyright-application-skill.git

2. 安装依赖
cd qoder-chinese-copyright-application-skill/web && pip install -r requirements.txt

3. 启动服务
python3 app.py

4. 访问

查看 GitHub 仓库 查看文档
